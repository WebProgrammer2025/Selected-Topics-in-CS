CS 421 Course Project — Phase I
Project Title

A Fair Experimental Comparison of Dijkstra's, A, and Greedy Best-First Search Algorithms for Shortest Path Finding*


Track 2 — Comparative Study Track


Group 3

Project Description

This project investigates the performance of Dijkstra's algorithm, A*, and Greedy Best-First Search (GBFS) for shortest-path finding on two-dimensional grid maps.

The project will use a controlled and reproducible experimental setup in which all three algorithms are evaluated using the same grid maps, movement rules, start and goal conditions, edge costs, and evaluation metrics.

The experiments will vary grid size and obstacle density and will evaluate the algorithms using execution time, number of explored nodes, path cost/length, and success rate.

Phase I

Phase I focuses on the literature review and experimental design. The literature review examines existing pathfinding research and identifies limitations in comparing results across different experimental environments.

Phase II

Phase II will implement the three algorithms and conduct the planned experiments. The generated maps, source code, experimental configurations, and results will be maintained in this repository.
